# BOCH FERRO ROTTAMI

Production-ready Next.js + Tailwind website starter for BOCH FERRO ROTTAMI.

## Stack

- Next.js App Router
- TypeScript
- React
- Tailwind CSS v4
- Lucide React
- next/image

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

Then open http://localhost:3000.

## Before production

1. Replace placeholder values in `.env.local`.
2. Replace `NEXT_PUBLIC_SITE_URL` with the real domain.
3. Add the final phone, WhatsApp and email.
4. Complete the privacy/cookie pages.
5. Connect `ContactForm.tsx` to your preferred email/CRM/API endpoint.
6. Review all legal/business claims and add only verified authorizations.
7. Replace or self-host the Unsplash imagery if desired.

The supplied BOCH FERRO ROTTAMI logo is already installed at:

`public/images/boch-logo.png`

No Albo, RENTRI, ISO, authorization or certification claims are included.
